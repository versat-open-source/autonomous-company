# Observability Standard

- Production workloads MUST expose enough telemetry to diagnose availability, latency, errors and resource pressure.
- Logs MUST be structured where practical and MUST avoid secrets and sensitive payloads.
- Alerts MUST identify an owner and an actionable response.
- Agent executions SHOULD record model, versioned instructions, tool calls, approval events and outcome without retaining prohibited content.
- Critical projects MUST define recovery objectives and operational runbooks.
